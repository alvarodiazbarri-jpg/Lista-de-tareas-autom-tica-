# Tareas pendientes de Dilo

Lista de mejoras para la app. Marca con [x] lo que esté hecho.

## Próximas
- [ ] **Unir Dilo con «Mi agenda» (citas) y las recetas**: que desde la voz se puedan crear citas («cita con el dentista el martes a las 10») y guardar recetas.
  - Problema: «Mi agenda» guarda los datos en la base de datos de Claude, que solo funciona dentro de claude.ai, y Dilo está en GitHub. No pueden compartir datos tal cual.
  - Hace falta elegir cómo unirlas (ver opciones en la conversación).
- [ ] **Guardar las listas en la nube** (sincronización): para verlas en varios dispositivos y no perderlas si se borra el navegador. Es el paso necesario para lo siguiente.
- [ ] **Apuntar con el móvil bloqueado**: un atajo de Siri (iPhone) o de Google/Tasker (Android) que dicte la idea y la envíe a la nube; Dilo la recoge en la Bandeja de entrada al abrirse.
